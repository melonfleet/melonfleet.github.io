Flotilla · by melonfleet

Apple’s containers, with a window.

Apple shipped container for macOS and left it on the command line. Flotilla is the native app on top: containers, images, volumes, networks and the virtual machines they run inside — plus a real terminal in every container. Free, no account, no telemetry.

What it does

Everything goes through Apple’s own container CLI.

Flotilla shows the exact command it used, so nothing happens that you could not have typed yourself.

$ container run -d --name api -p 8080:80 nginx:latest

Run and watch

Start, stop and delete containers, and see live stats and logs while they run.

Shell straight in

A real terminal in any container or machine, without leaving the window.

Everything else too

Images, volumes, networks and the virtual machines your containers run inside.

Requirements & install

Two things, and nothing else.

01

macOS 26 or later

On Apple silicon.

02

Apple’s container CLI

Installed separately from apple/container. Flotilla drives that tool; it does not bundle or replace it.

03

Nothing else

No account, no telemetry. Signed with a Developer ID and notarised by Apple.

Flotilla is not released yet. There is a signed, notarised 0.9.0 for testing; 1.0 follows. A download link appears here when the repository is public and a release exists.

More fruit on the way.
